## 3. ВИКТОРИНЫ — движок `engine/_kviz/quiz.py`
```
python3 $E/_kviz/quiz.py <папка>      # в папке quiz.json (+ cover.json для религии)
```
Скрипт сам: озвучивает весь текст одним запросом, режет по строкам (распознаванием), проверяет совпадение, рисует кадры, тиканье/«динь»/музыку, обложку, пишет `output/<out>_PUBLISH.mp4` и `output/<out>_cover.jpg`. Выход > 175 с → ошибка: убери 1–2 вопроса.

Образцы quiz.json (возьми и измени): `engine/_kviz/primery/` —
`ayat_sira.json` (текстовая, RU), `ruhun_sira.json` (текстовая, AZ), `bayraq_az.json` / `flags_en.json` (флаги AZ/EN).

### Типы вопросов (`items[].mode`)
- `text` — вопрос + 3 варианта (`options`, `correct` = номер с 0, `source` = источник). Для религии и для «столицы/факты» в истории.
- `flag` — флаг (`iso2`, двухбуквенный код в нижнем регистре: `az`, `it`…), `answer` — название страны.
- `shape` — контур страны (`iso` = трёхбуквенный ADM0_A3: `ITA`, `AZE`, `FRA`…), `answer`.
- `level`: `easy` / `medium` / `hard` — по возрастанию к концу.

### Правила викторин
- **РЕЛИГИЯ (AYAT LUMA, Ruhun Qidası): БЕЗ МУЗЫКИ ВО ВСЕХ РОЛИКАХ (и викторины, и рассказы, и сира)** — в quiz.json `"religion": true`, `"music": ""` (quiz.py и так выключает музыку для AYAT/RUHUN). Только голос и тихие звуки (тик, «динь»). **Только МУЖСКИЕ голоса** (Achird, Sadachbia, Charon, Iapetus, Schedar, Umbriel…), никаких женских. Правило пользователя 16.11.2026.
- Хук в первой фразе (`intro_voice`): «Только 1 из 10 ответит на все…», «Последние 3 почти никто не угадывает…». Обложка — тоже вокруг хука.
- Религия: 10 вопросов, 3 варианта, у каждого ответа — **достоверный источник с номером** (аль-Бухари, Муслим…; Коран — номер аята). Только однозначные факты, без спорных вопросов (кто «первый» принял ислам и т.п. — не брать). Ответ в озвучке — только сам ответ («Сорок лет.»), без «Правильный ответ:» (это ломает нарезку).
- Флаги/контуры: 15 вопросов, 5 лёгких → 5 средних → 5 сложных. **Номера вопросов НЕ озвучивать** (`q_voice: ""` — номер и так на экране), кроме вопроса 6 (`q_voice`: «İndi çətinləşir!» / «Now it gets harder!») и 11 («Bunları yalnız əsl bilici tapar!» / «Only true experts get these!»). **Ответ — только название страны** (`a_voice`: «İtaliya!» / «Italy!»), без «Bu…» / «It's…». Иначе короткие строки слипаются и ответ звучит не под тем флагом (ошибка 16.11.2026).
- **ПРОВЕРКА ОТВЕТОВ обязательна:** quiz.py в конце печатает по каждому вопросу «nado: … | slyshno: …» и итог `PROVERKA OTVETOV`. Если «PLOHO» (код выхода 5) — НЕ публикуй: перезапусти с `rm -rf <папка>/_q/voice` (новая озвучка) или исправь текст. В отчёт добавь строку «проверка ответов: все N совпали».
- Страны и вопросы не повторять: проверь прошлые викторины в очереди и на канале (раздел 9 общей инструкции).
- Текст поста: хук + «напиши результат в комментариях: сколько из 10/15?» + «отправь другу» + подписка + для религии список источников + хэштеги. YouTube title — хук + «#shorts» для истории.
- Перед загрузкой посмотри 4 кадра (вопрос, отсчёт, ответ, финал) и прочитай лог «proverka ozvuchki: sovpadenie» (должно быть ≥ 0.6) и строки «VNIMANIE».
